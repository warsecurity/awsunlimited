## Overview

LOSTBUG is an Android application that provides **free, unlimited hosting** for any file type and size – including tools, executables, scripts, and other payloads. Every uploaded file receives a **permanent public URL**.

## Features

- **Unlimited file size** – Upload files of any size. *(Note: Very large files may upload slowly.)*
- **Permanent public URL** – Links do not expire.
- **Infinite storage** – No storage caps.
- **Complete anonymity if VPN ACTIVE** – No logs, no tracking. Use a VPN for enhanced privacy.
- **Universal file support** – Any file type accepted.
- **Instant sharing** – One-click distribution link.

---

## How It Works

1. Download and install the APK (requires Android 6.0+).
2. Open the app and authenticate with your credentials.
3. Tap **Select File** and choose your file or payload.
4. Tap **Begin Upload** – a permanent public URL will be generated.
5. Copy the link and distribute it anywhere (Discord, email, forums, etc.).
